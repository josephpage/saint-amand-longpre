# Guide de rédaction pour le secrétariat

Le site se met à jour depuis **https://cms.saintamandlongpre.fr/wp-admin/**. Après chaque
publication, le site public est reconstruit automatiquement : comptez **3 à 5 minutes** avant de
voir la modification en ligne.

## Publier une actualité

1. Articles → **Ajouter un article**.
2. Titre court et précis (« Travaux rue de la Poste du 12 au 28 avril »).
3. Rédigez le texte, puis choisissez une **catégorie** (Urbanisme, Vie locale…) dans le panneau de
   droite.
4. **Image mise en avant** : une photo horizontale, avec un **texte alternatif** qui la décrit
   (obligation d'accessibilité).
5. **Prévisualiser** pour vérifier le rendu sur le site, puis **Publier**.

## Annoncer un évènement

Évènements → **Ajouter un évènement** : titre, description, puis les champs **Début**, **Fin**,
**Lieu** et **Adresse**. L'évènement apparaît dans l'agenda, sur l'accueil (trois prochains) et dans
le calendrier auquel les habitants peuvent s'abonner. Il passe tout seul dans « Évènements passés ».

## Afficher un message important (canicule, travaux, coupure d'eau)

Alertes → **Ajouter une alerte** : titre, message court, niveau (Information, Vigilance, Urgence),
lien facultatif et **date de fin**. L'alerte s'affiche en haut de toutes les pages et disparaît
d'elle-même le lendemain de la date de fin.

## Publier un compte rendu du conseil

Séances du conseil → **Ajouter une séance** : titre « Séance du 7 septembre 2026 », date, puis le
PDF dans **Compte rendu**.

## Joindre un document à une page

Dans le texte, ajoutez un bloc **Fichier** (bouton « + » → Fichier) et choisissez le PDF. Il
s'affiche comme une pièce jointe à télécharger. Nommez le document clairement dans la médiathèque.

## Modifier les horaires, le téléphone ou la photo d'accueil

Réglages → **Mairie**. Les horaires s'écrivent une ligne par créneau : numéro du jour (1 = lundi),
heure d'ouverture, heure de fermeture, par exemple `5 14:00 16:30`.

## Être bien trouvé sur Google et par les assistants IA

- **Titre** : reprenez les mots des habitants (« Inscription à l’école maternelle », pas
  « Scolarité 2026 »).
- **Première phrase** : la réponse directe (qui, quoi, quand, où, combien). Les moteurs et les IA
  la reprennent souvent telle quelle.
- **Extrait** (panneau de droite) : une ou deux phrases qui résument la page ; elles servent de
  description dans les résultats de recherche.
- **Dates, horaires, lieux, tarifs** écrits en toutes lettres dans le texte, pas seulement dans un PDF
  ou une image.
- **Mettre à jour plutôt que dupliquer** : corrigez la page existante (la date « Mis à jour le »
  change toute seule) au lieu de publier une nouvelle page sur le même sujet.
- Les horaires, le téléphone et l'adresse se modifient uniquement dans Réglages → Mairie : ils se
  répercutent partout (pages, données pour Google, réponses des IA).

## Bonnes pratiques

- Un titre par idée, des phrases courtes, des listes à puces pour les pièces à fournir.
- Pas de texte en MAJUSCULES ni de mise en forme par couleurs.
- Toujours un texte alternatif pour les images informatives.
- Préférer une page web à un PDF quand c'est possible (plus lisible sur téléphone et accessible).
